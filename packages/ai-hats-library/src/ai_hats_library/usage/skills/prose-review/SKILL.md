# Prose Review

An editor's report on a finished draft: findings with quoted lines, in a fixed
order, before a single edit is proposed.

## When to Use

- A draft exists — yours or the author's — and it should be better, shorter,
  or checked. The text that does not exist yet is `article-outline`'s job;
  the facts in it are `claim-evidence-check`'s — run that one alongside.
- Any language; the style checks live in per-language references.
- How the editor behaves — six rules, each with the careless move it replaces —
  is `references/editor-conduct.md`. Read it before the first report of a
  session; it is what separates a proposal from a fait accompli.

## Procedure

1. **Read the whole text once.** Then write one sentence: who reads this and
   what they leave with. If the sentence will not come, that is finding #1.
2. **Essence.** Does the text lead with that sentence's substance? Quote the
   line where the point actually surfaces; everything above it is a candidate
   cut or move.
3. **Repetition.** Each idea once. Pair the sentences or paragraphs that say
   one thing in two ways; quote both; name the one to keep.
4. **Value per section.** Under every heading: what does the reader get here?
   No answer → merge or cut.
5. **Style.** Run the language reference — `references/style-ru.md` or
   `references/style-en.md` — including its list of machine-prose tells.
   Quote each hit next to the rule it breaks.
6. **Terms and voice.** A glossary or a voice reference composed into the
   session or present in the project is the judge for terms and style. With
   none on the table, write "no reference — style left alone" and do not
   normalize.
7. **Report** in the shape of `references/critic-rubric.md`, written in the
   language of the text under review — a quoted line is never translated.
   Findings only, no rewritten passages.
8. The author decides. Apply what is accepted, run one more pass, and stop
   when it adds nothing new — or after the second round.

## Completion

- The report opens with the one-sentence purpose and lists findings by axis,
  each quoting the line it is about, closing with one verdict line.
- No passage was rewritten before the author chose.
- Validation — RED: a draft whose point first surfaces in the third paragraph
  and carries two paragraphs saying one thing comes back as "reads well, a few
  small edits". GREEN: the report opens with the purpose sentence and quotes
  the buried point and both twins.

## Anti-Patterns

- Rewriting where a finding was due.
- "Overall good" as the opening line.
- Normalizing style with no voice reference on the table.
- A finding without the quoted line — the author cannot act on it.
